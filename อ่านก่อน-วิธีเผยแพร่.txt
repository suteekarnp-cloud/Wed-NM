เว็บไซต์ครูมนณัชญ์ กุลวรรณ — ชุดไฟล์สำหรับเผยแพร่เป็นเว็บจริง
==================================================================

ในโฟลเดอร์นี้มี
  index.html   = ตัวเว็บทั้งหมด (หน้าตา เนื้อหา ใบงาน โค้ด อยู่ในไฟล์นี้ไฟล์เดียว)
  img/         = รูปภาพ
  svg/         = แผนภาพวงจรและผังงาน
  .nojekyll    = ไฟล์ว่าง ไว้ให้ GitHub Pages แสดงผลถูกต้อง (ห้ามลบ)
ต้องอัปโหลดทั้งหมดนี้ไปด้วยกันเสมอ


วิธีที่ 1 — GitHub Pages (แนะนำ: ฟรี ถาวร ลิงก์ไม่หมดอายุ)
------------------------------------------------------------------
1) สมัคร/เข้าสู่ระบบ https://github.com (แนะนำให้ใช้บัญชีของครูมนณัชญ์เอง)
2) มุมขวาบนกด  +  > New repository
     Repository name : teacher-site   (ตั้งชื่ออื่นได้ ชื่อนี้จะอยู่ในลิงก์)
     เลือก Public > กด Create repository
3) ในหน้าที่ขึ้นมา กดลิงก์ "uploading an existing file"
4) แตกไฟล์ zip ก่อน แล้วลาก "ของข้างในโฟลเดอร์" ทั้งหมด (index.html, img, svg, .nojekyll)
   ลงในหน้าเว็บ > รออัปโหลดเสร็จ > กด Commit changes
   * ไฟล์ .nojekyll ถูกซ่อนในบางเครื่อง ถ้าลากไม่ติดก็ไม่เป็นไร เว็บยังใช้ได้
5) ไปที่ Settings > Pages
     Source = Deploy from a branch
     Branch = main   โฟลเดอร์ = / (root)   > Save
6) รอ 1–2 นาที รีเฟรชหน้า Settings > Pages จะเห็นลิงก์เว็บ เช่น
     https://ชื่อบัญชี.github.io/teacher-site/
   ลิงก์นี้ส่งให้ใครก็เปิดดูได้ทันที ไม่ต้องล็อกอิน


วิธีที่ 2 — Netlify (ง่ายที่สุด ลากวางครั้งเดียว)
------------------------------------------------------------------
1) สมัคร https://app.netlify.com (ใช้บัญชี Google ได้)
2) ไปที่ https://app.netlify.com/drop แล้วลาก "โฟลเดอร์ที่แตกจาก zip" ทั้งโฟลเดอร์ลงไป
3) ได้ลิงก์ทันที เช่น https://ชื่อสุ่ม.netlify.app
   เปลี่ยนชื่อได้ที่ Site configuration > Change site name
   (ต้องสมัคร/ล็อกอินก่อนลาก เว็บถึงจะอยู่ถาวร)


วิธีแก้ไขเนื้อหาหลังเผยแพร่
------------------------------------------------------------------
1) เปิดเว็บโดยเติม ?edit ต่อท้ายลิงก์ เช่น
     https://ชื่อบัญชี.github.io/teacher-site/?edit
   จะเข้าโหมดแก้ไข (แก้ข้อความ เพิ่มหัวข้อ วางโค้ด เพิ่มรูป ได้เหมือนเดิม)
   * คนทั่วไปที่เปิดลิงก์ปกติจะไม่เห็นปุ่มแก้ไข และแม้มีคนลองเติม ?edit
     ก็แก้ได้แค่ในเครื่องตัวเอง เปลี่ยนเว็บจริงไม่ได้ เพราะไม่มีสิทธิ์อัปโหลด
2) แก้เสร็จกดปุ่ม "ดาวน์โหลดไฟล์เว็บ" ด้านล่าง > จะได้ไฟล์ index.html ใหม่
3) นำ index.html ใหม่ไปอัปโหลดทับไฟล์เดิม
     GitHub : เข้า repository > Add file > Upload files > ลาก index.html > Commit changes
              (รอ 1–2 นาที เว็บจริงจะเปลี่ยน)
     Netlify: เข้าเว็บไซต์ > Deploys > ลากโฟลเดอร์ทั้งหมด (ที่มี index.html ใหม่) ลงไปอีกครั้ง
4) ระหว่างแก้ ระบบจำงานที่ยังไม่ดาวน์โหลดไว้ในเบราว์เซอร์ให้ เผื่อเผลอรีเฟรช

เรื่องรูปภาพและไฟล์
  - เพิ่มรูปจากเครื่องในโหมดแก้ไขได้เลย ระบบย่อรูปและฝังไว้ใน index.html ให้อัตโนมัติ
  - ไฟล์ PDF / Word / PowerPoint ให้อัปขึ้น Google Drive ตั้งค่าแชร์ "ทุกคนที่มีลิงก์"
    แล้ววางลิงก์ในใบงาน (ไฟล์ใหญ่ไม่ควรใส่ในเว็บโดยตรง)


อยากให้อยู่ใน Google Sites ด้วย
------------------------------------------------------------------
ใน Google Sites กด แทรก (Insert) > ฝัง (Embed) > ตามURL > วางลิงก์ GitHub/Netlify
หรือใส่เป็นปุ่ม/ลิงก์ในเมนูของ Google Sites ให้กดไปที่เว็บนี้


ข้อควรระวัง
------------------------------------------------------------------
- เว็บนี้เปิดสาธารณะ: ภาพนักเรียนควรได้รับความยินยอมก่อน (PDPA)
- GitHub แบบฟรีต้องเป็น Public หมายความว่าไฟล์ทั้งหมดในที่เก็บมีคนเปิดดูได้ —
  อย่าใส่ข้อมูลส่วนตัว เบอร์โทร ที่อยู่ หรือรหัสผ่านใด ๆ ลงในเว็บ
- เก็บไฟล์ zip ชุดนี้ไว้เป็นสำรองเสมอ
